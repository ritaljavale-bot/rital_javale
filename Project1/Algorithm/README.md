# Algorithm - Token System

1. Start the program.
2. Initialize head = NULL.
3. Display the menu and accept the user's choice.
4. To add a token, create a new node dynamically.
5. If the list is empty, assign the new node to head.
6. Otherwise, traverse to the last node and add the new node.
7. To serve a token, check whether the list is empty.
8. If the list is not empty, remove the first node and move head to the next node.
9. To search, traverse the list and compare each token number with the required token.
10. Display all pending tokens by traversing from head.
11. Continue operations until the user selects Exit.
12. Stop the program.
