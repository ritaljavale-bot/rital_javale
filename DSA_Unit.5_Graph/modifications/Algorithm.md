### Algorithm

1. Start.
2. Enter the number of cities and roads.
3. Create a weighted graph using an adjacency list.
4. Enter the road details and their distances.
5. Select the source city.
6. Initialize all distances to infinity and set the source distance to zero.
7. Find the unvisited city with the minimum distance.
8. Update the distances of neighboring cities if a shorter path is found.
9. Repeat Steps 7 and 8 until all reachable cities are processed.
10. Display the shortest distances.
11. Select an operation:

    * **A:** Change the source city and recalculate distances.
    * **B:** Enter a destination city and display the complete shortest path.
    * **C:** Update a road's weight and recalculate distances.
12. Repeat the operations until the user selects Exit.
13. Stop.
