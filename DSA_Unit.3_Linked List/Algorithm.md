Algorithm
1. Start.
2. Initialize front = NULL, rear = NULL and top = NULL.
3. Add a new token to the rear of the Queue.
4. Push the new order onto the Stack.
5. Search for a token by traversing the Queue.
6. Serve the first customer by deleting the front node.
7. Display all pending tokens.
8. View the latest order using the Stack's PEEK operation.
9. Undo the latest order using POP.
10. Stop.
