## Problem Statement

Develop a Smart Canteen Order and Token Management System using Stack and Queue implemented with linked lists. The Queue is used to manage customer food-order tokens according to the FIFO (First In, First Out) principle, ensuring that the customer who places an order first is served first. The Stack is used to manage the most recently placed order for undo operations, following the LIFO (Last In, First Out) principle.

The system should allow staff to add tokens, serve customers, search for tokens, display pending tokens, view the latest order, and undo the latest order.
