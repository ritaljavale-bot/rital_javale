### Algorithm
1.  Start.
2.  Create a binary tree using the given node values.
3.  Check whether the current node is NULL.
4.  If it is NULL, return true.
5.  Check whether the left child is smaller than the current node.
6.  Check whether the right child is greater than the current node.
7.  Recursively validate the left and right subtrees.
8.  If all checks pass, display that the tree is a valid BST.
9.  Otherwise, display that the tree is not a valid BST.
10. Stop.
